# 稿紙 · 寫作軟件（Phase 1 · 本機完整版）

## 這是什麼

一個正文／備註左右聯動的中文寫作軟件。這個版本是 **Phase 1**：所有資料都加密保存在你目前使用的瀏覽器裡（IndexedDB），不需要網路也能完整使用。跨裝置同步（Google 帳號 + Google Drive）留待 Phase 2。

## 如何開始使用

**最簡單的方式**：直接用瀏覽器打開 `index.html` 就能用。

> 直接用 `file://` 打開時，「離線安裝／PWA」與 Service Worker 快取這兩個功能不會啟用（瀏覽器安全限制），但編輯、加密、自動保存全部正常運作。若想要完整的「加到主畫面」安裝體驗，可參考下方「之後想部署」的做法，用任何一種免費靜態網站託管服務放上去即可。

## 第一次使用

打開後會先要求你**設定一組密碼**。這組密碼用來加密你所有的內容，只存在於你的裝置上：

- 忘記密碼將**無法救回**任何資料，請務必把密碼記在安全的地方。
- 之後想在另一台裝置延續同一份內容，用側邊欄「🔒 備份與還原」匯出加密備份檔，傳到另一台裝置後在該裝置首次啟動時選「從備份檔匯入」（用同一組密碼）即可。

## 檔案說明

```
index.html            主程式（介面、邏輯、加密全部在這一個檔案裡）
manifest.webmanifest   PWA 設定檔（讓瀏覽器知道如何「安裝」這個 App）
sw.js                  Service Worker（離線快取，需透過 http(s) 開啟才會生效）
icons/                 App 圖示
```

## 之後想部署成「打開網址就能用」

之後要接上 Google 帳號登入與 Google Drive 同步（Phase 2）時，Google 的 OAuth 設定要求網站有一個真實網址（不能是 `file://`），到時候只需要把這整個資料夾原封不動放到下面任一個免費服務即可：

- **GitHub Pages**：新增一個 repository，把這些檔案傳上去，在 repository 設定裡開啟 Pages 功能即可取得網址。
- **Cloudflare Pages** / **Netlify** / **Vercel**：把這個資料夾拖曳上傳即可，通常幾秒鐘就能拿到網址。

放上去之後，用手機或電腦瀏覽器打開該網址，就能看到「加到主畫面／安裝」的選項，體驗上會更接近原生 App。

## 已知限制（Phase 1）

- 尚未接上 Google Drive，跨裝置同步目前靠「匯出備份檔 → 手動傳到另一裝置 → 匯入」完成。
- 多裝置離線編輯衝突的合併介面尚未設計（目前每次匯入備份是整份覆蓋，請留意匯入前的提示）。
- 若清除瀏覽器資料（清除瀏覽紀錄時勾選「Cookie 與網站資料」），本機的加密資料庫也會一併被清除，請養成定期用「備份與還原」匯出備份檔的習慣。
